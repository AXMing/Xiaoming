# 🎩 分院帽测试器 - Sorting Hat Quiz

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/AXMing/sorting-hat-quiz)

一个精美的哈利波特主题分院帽测试网站，帮助你发现自己属于霍格沃茨的哪个学院。

## ✨ 特性

- 🎨 **精美视觉设计** - 魔法主题配色，星空背景，粒子动画
- 🎭 **8道测试题目** - 全面评估你的性格特质
- 🎩 **分院帽动画** - 逼真的分院帽形象和思考动画
- 🏰 **四大学院** - 格兰芬多、斯莱特林、拉文克劳、赫奇帕奇
- 📱 **响应式设计** - 完美支持桌面和移动设备
- 🎵 **音效支持** - 魔法音效增强体验
- ⌨️ **键盘支持** - 可使用数字键 1-4 快速选择
- 📤 **分享功能** - 一键分享测试结果

## 🚀 一键部署

### 方式一：Vercel 一键部署

点击上方的 **"Deploy with Vercel"** 按钮，即可快速部署到你的 Vercel 账号。

### 方式二：手动部署到 Vercel

1. 安装 Vercel CLI
```bash
npm i -g vercel
```

2. 登录 Vercel
```bash
vercel login
```

3. 部署项目
```bash
cd sorting-hat
vercel --prod
```

### 方式三：Git 部署

1. 将代码推送到 GitHub/GitLab
2. 在 Vercel 控制台导入项目
3. 自动部署完成

## 🛠️ 本地开发

```bash
# 进入项目目录
cd sorting-hat

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 或者使用 Python
python -m http.server 8080
```

访问 http://localhost:3000 或 http://localhost:8080
